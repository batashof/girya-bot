# 04. UX бота: команды и сценарии

Принцип: **минимум набора текста**. Всё, что можно, — инлайн-кнопки. Утренний сценарий должен проходиться одной рукой, не глядя.

## Команды

Меню команд у поля ввода бот выставляет сам (`setMyCommands`) из `menuCommands` в `src/bot/ui/texts.ts` — на первом cron после деплоя и только когда список поменялся. Руками в @BotFather его не правят: так новая команда не потеряется из меню, как когда-то `/train`. `/ping` в меню нет — это служебная проверка.

| Команда | Что делает |
| --- | --- |
| `/start` | Онбординг (только при первом запуске), дальше — краткая справка |
| `/train` | Выбрать тренировку: программа дня или тема (шея, лопатки, ноги…), переключить режим |
| `/today` | Тренировка на сегодня + кнопка «Начать» |
| `/go` | Сразу войти в пошаговый режим |
| `/pain` | Отметить боль в шее/спине сейчас → бот перестраивает день |
| `/skip` | Пропустить сегодня (спросит причину: устал / нет времени / болит / болею) |
| `/stats` | Частота, минуты, тренд по шее, ступени лестниц в базовых движениях |
| `/streak` | Текущая и рекордная серия |
| `/swap` | Заменить упражнение в текущей тренировке |
| `/gif <код>` | Прислать боту гифку с этой подписью — она заменит схему движения в карточке |
| `/settings` | Время, часовой пояс, рост/вес/возраст, инвентарь, режим, уровни лестниц |
| `/pause 3` | Пауза на N дней (болезнь, поездка) — без потери серии |
| `/export` | CSV со всеми сессиями |
| `/help` | Список команд |

## Онбординг (`/start`, один раз)

Всё кнопками, кроме числовых значений. Занимает минуту, любой ответ потом меняется в `/settings`.

1. **Часовой пояс** — кнопки с 3–4 частыми вариантами + «другой» (текстом).
2. **Во сколько напоминать?** — кнопки: 06:30 / 07:00 / 07:30 / 08:00 / другое.
3. **Рост, вес, возраст** — одной строкой: `190 73 30`. Нужны для стартовых уровней лестниц и поправок (длинные рычаги — старт на ступень ниже).
4. **Какие гири есть?** — текстом: `5, 5`. По умолчанию пара пятёрок.
5. **Что ещё есть?** — турник / резина / рюкзак (мультивыбор, по умолчанию ничего). Программа рассчитана на пару гирь и больше ничего не требует; отмеченное здесь только добавляет варианты.
6. **Уровень** — «начинаю/возвращаюсь» или «тренируюсь регулярно».

Вопроса «сколько минут готов тратить» нет: время тренировки не планируется (ADR-018).

Финал: показывает завтрашний день и предупреждение из [10-safety.md](10-safety.md).

## Настройки (`/settings`)

Меню кнопками, каждый пункт правится отдельно:

```
   ⚙️ Настройки
   [ ⏰ Время: 07:30 ]     [ 🌍 TZ: Europe/Warsaw ]
   [ 🏋️ Инвентарь ]        [ 📏 190/73/30 ]
   [ 🗓 Режим: ежедневно ]
   [ 📶 Уровни ]            [ ⏸ Пауза ]
```

**Режим** — `ежедневно` (утреннее напоминание и вечерний пинг) или `по запросу` (их нет, тренировка начинается через `/train`). Программа дня работает в обоих режимах (ADR-016).

**Уровни упражнений** — ручная правка ступени в любой лестнице (`Отжимания: 4 → 3`) на случай, когда алгоритм ошибся или после перерыва. Без этого экрана бот был бы упрямее, чем нужно.

## Утренний сценарий

```
07:30  🏋️ Понедельник — Спина и осанка
       Неделя 1 из 4

       Шея сегодня?
       [ 0 ок ] [ 1 тянет ] [ 2 болит ] [ 3 сильно ]
```

Ответ 0–1 — день идёт как есть. Ответ 2 — из дня убираются упражнения с `neck_safe = 0`, объём режется на 30%. Ответ 3 — день целиком заменяется на восстановительный протокол (W-G) и бот напоминает про красные флаги.

```
       1. Шейный протокол, 7 упр.
       2. Тяга одной рукой в наклоне 5 кг — 3×15 / сторону
       3. Prone Y — 2×12
       …
       8. Растяжка груди в дверном проёме — 2×45 с

       [ ▶️ Начать ]  [ 🕐 Через час ]  [ 🔁 Заменить упражнение ]  [ ⏭ Пропустить ]
```

## Пошаговый режим

**Одно упражнение — одно сообщение.** У сообщения сверху схема движения (гифка), под ней задание и техника, снизу кнопки. Пока идут подходы одного упражнения, сообщение перерисовывается на месте; когда упражнение закончено, оно сворачивается в строку итога, а следующее приходит новым сообщением. Так чат остаётся историей утра, а не одним мигающим экраном.

```
   [ схема движения: рисованная фигура, зацикленная ]

   ▰▰▰▱▱▱▱▱ упражнение 8 из 12

   Тяга одной рукой в наклоне
   Подход 2 из 3 · сначала отдых 30 с

   🔁 15 повторов на каждую сторону
   ⏱ Каждый повтор ~3 с: 1 с вверх, 2 с вниз
   🏋️ Гиря 5 кг

   Как делать:
   1. Поставь левую ладонь и левое колено на сиденье стула, правая стопа на полу.
   2. Спина параллельна полу и прямая, взгляд в пол.
   3. Гиря в правой руке висит прямо под плечом.
   4. Тяни локтем назад вдоль тела к карману, лопатка идёт первой.
   5. Опускай в полтора раза медленнее, чем поднимаешь.

   ⚠️ Не надо: тянуть рукой и разворачивать корпус вслед за гирей.

   Как прошло? 😮‍💨 тяжело · 👌 нормально · 😴 легко

   [ 😮‍💨 ]  [ 👌 ]  [ 😴 ]
   [ 🤕 Больно ]  [ ⏭ Пропустить упражнение ]
```

Строгий порядок блоков, чтобы глаз не искал: **где я → что за упражнение → какой подход → сколько повторов → сколько длится один повтор → как делать**.

**Задание — ровно две величины: сколько повторов и сколько секунд на повтор** (ADR-017). Раньше рядом стояли «3 подхода по 10 повторов», «примерно 20 с на подход» и «держи 5 секунд» в технике, и эти числа не складывались друг с другом. Теперь:

| Что за упражнение | Строки задания |
| --- | --- |
| Движение | `🔁 15 повторов на каждую сторону` · `⏱ Каждый повтор ~3 с: 1 с вверх, 2 с вниз` |
| Удержание, одно | `🔁 1 повтор` · `⏱ Держи 30 с` |
| Удержание, несколько | `🔁 3 повтора` · `⏱ Каждый повтор — держи 30 с, между повторами пауза 5 с` |
| Шаги (переноска) | `🔁 40 шагов на каждую сторону` · `⏱ Каждый шаг ~1 с` |
| Прогулка, долгое удержание | `⏱ 30 мин без остановки` |

- **Подход назван всегда**: `Подход 2 из 3` или `Один подход`. Карточка показывает один подход, повторы в строке `🔁` — на этот подход, а не на всё упражнение.
- **Отдых стоит перед подходом, а не «между»**: карточка следующего подхода приходит сразу после оценки предыдущего, поэтому на ней и написано `сначала отдых 30 с`. У первого подхода отдыха нет.
- **В технике нет чисел.** Секунды и повторы живут только в строках задания; `cues` описывают движение, и сборка сида падает, если в них попадёт «держи 5 секунд» или «10 раз» (`scripts/build-seed.mjs`).
- **Прогресс-бар** заполняется по подходам, а подпись считает упражнения: за счёт этого он двигается и внутри упражнения из трёх подходов.
- **Времени нет нигде, кроме секунд на повтор** (ADR-018): ни «осталось ~N мин», ни «~15 мин» в плане. Сколько займёт тренировка, бот не считает и под бюджет её не режет.
- **Шкала «как прошло»** — три кнопки без подписей: они и записывают подход, и двигают лестницу, и открывают следующий экран. Ничего не происходит само, переход всегда по кнопке. Подписи не нужны, потому что строкой выше стоит расшифровка, а сам ряд читается как шкала слева направо.
- **👌 нормально** — это «всё устраивает»: считается выполнением по цели и наравне с «легко» ведёт вверх по лестнице через две тренировки подряд ([05-training-program.md](05-training-program.md)).
- **Больно / Пропустить** остались с подписями: они снимают упражнение целиком, и попадать туда мимо шкалы не должно. Добивать через боль программа не умеет ([10-safety.md](10-safety.md)).

Шаг — это упражнение, а не экран: шейный протокол разворачивается по одному, потому что семь названий в одном сообщении не объясняют, что делать руками и головой. Нажатий за утро больше, зато каждое движение показано. Позиция хранится в `ui_state`, поэтому `/go` после закрытого чата продолжает с места остановки.

### Схемы движения

К каждому упражнению из шаблонов дней и лестниц есть рисованная схема: не видео с человеком, а подсказка «куда двигаться» — линия спины, траектория снаряда, что сгибается, а что стоит. Фигура объёмная и одетая, дальние рука и нога бледнее ближних; повтор идёт в живом темпе — разгон и торможение, пауза в крайней точке, опускание медленнее подъёма, как в технике. Генерируются `pnpm demos:build` (см. `scripts/build_demos.py`), лежат в репозитории и уходят в бандл воркера. После первой отправки бот запоминает `file_id` и больше файл не грузит (ADR-014). Своя гифка вместо схемы — `/gif <код>`, она всегда сильнее встроенной.

Отдельного экрана с техникой нет: она целиком в карточке, а ссылок на чужие ролики бот не даёт.

Если карточка не влезает в подпись к медиа (лимит Telegram — 1024 символа), она уходит обычным сообщением: техника важнее картинки.

Финал:

```
   ✅ Готово за 14 мин.
   Серия: 12 дней 🔥
   Завтра: Вторник, Ноги и таз.
```

## Тренировка по теме (`/train`)

Меню формата тренировки:

```
   Какую тренировку?
   [ 📅 Программа дня ]  [ 🎯 По теме ]
   [ 🩹 Шея и надплечья ]
   [ 🗓 Режим: по запросу ]
```

«По теме» — список групп упражнений справочника. Тема — это `group_code`, упражнения внутри — любые, в любом порядке:

```
   [ 🦴 Шея ]              [ 🎯 Лопатки и осанка ]
   [ 🔙 Спина: тяги ]      [ 🍑 Задняя цепь ]
   [ 💪 Жимы и плечи ]     [ 🦵 Ноги ]
   [ 🧱 Корпус ]           [ 🧘 Мобильность ]
```

Внутри темы — кнопка на каждое упражнение, доступное по инвентарю. Сделанные в этой тренировке помечены ✅. В день боли в шее ≥2 упражнения с `neck_safe = 0` спрятаны, и список пишет, сколько их.

```
   🦴 Шея
   Выбери упражнение.
   ✅ — уже сделано в этой тренировке.

   [ ✅ Chin tuck (подбородок назад) ]
   [ Изометрия сгибания шеи ]
   …
   [ ⬅️ Темы ]  [ 🏁 Закончить ]
```

Выбранное упражнение приходит той же карточкой, что и в программе дня: схема движения, задание, техника, шкала «как прошло». Вместо прогресс-бара в шапке — тема и номер упражнения (`🦴 Шея · упражнение 2`): сколько их будет, заранее неизвестно. Под шкалой — «⬅️ К списку»: бросить упражнение на полпути, записанные подходы остаются. После последнего подхода карточка сворачивается в строку итога, и снова приходит список.

Доза — своя у каждого упражнения (`exercises.dose_*`, ADR-017): подходы, повторы или удержания, отдых. Если упражнение — ступень лестницы, повторы и время повтора берутся с той ступени, где стоит пользователь, с его текущей целью. «🏁 Закончить» закрывает сессию и пишет итог: сколько упражнений и минут. Тренировка по теме пишется с `kind = 'theme'`, на лестницы и серию не влияет и в недельном отчёте считается отдельно (ADR-016).

Отдельных микро-блоков (`/mini`) больше нет (ADR-017): «размять шею между делами» — это тема «Шея» и одно выбранное упражнение.

## Комплекс (`/train` → 🩹)

Готовый набор упражнений под одну проблему (ADR-018). Кнопка на каждый комплекс стоит прямо в меню `/train`. В отличие от темы, упражнения не выбираются: порядок и дозы заданы, комплекс проходится от начала до конца той же карточкой, что и программа дня.

```
   🩹 Шея и надплечья
   Против боли там, где шея переходит в плечи — от лямок рюкзака и долгой езды. …

   11 упражнений по порядку.
   На лестницы и серию комплекс не влияет — он для проблемы, а не по плану.
```

Карточка — как в программе дня, над прогресс-баром — название комплекса:

```
   🩹 Шея и надплечья
   ▰▰▱▱▱▱▱▱ упражнение 3 из 11

   Подъём гири в сторону
   Подход 2 из 3 · сначала отдых 45 с

   🔁 12 повторов на каждую сторону
   ⏱ Каждый повтор ~4 с: 1 с вверх, 3 с вниз
   🏋️ Гиря 5 кг
   …
   [ 😮‍💨 ]  [ 👌 ]  [ 😴 ]
   [ 🤕 Больно ]  [ ⏭ Пропустить упражнение ]
   [ ⏹ Закончить комплекс ]
```

- Каждый подход пишется в базу сразу; сессия — `kind = 'complex'`, сколько угодно раз в день. Лестницы и серию комплекс не трогает: его пункты не привязаны к лестницам (сборка сида запрещает в нём `follow_chain`).
- Инвариант шеи общий: при боли ≥2 упражнения с `neck_safe = 0` из комплекса уходят, и вступление пишет, сколько их убрано.
- Разгрузочная неделя комплекс не режет: это набор под проблему, а не ступень программы.
- Повторное нажатие кнопки комплекса посреди прохождения присылает текущую карточку заново, а не начинает сначала. «⏹ Закончить комплекс» закрывает сессию, сделанное остаётся.
- В недельном отчёте и `/stats` комплексы считаются отдельно: «комплексов 2».

Состав и обоснование комплекса «Шея и надплечья» — в [07-neck-and-back.md](07-neck-and-back.md).

## Вечерний пинг

Если к `evening_ping_at` сессия не в статусе `done`:

```
   Ещё не тренировался. Хотя бы шею и основное движение?
   [ ▶️ Сокращённая версия ]  [ ⏭ Пропустить сегодня ]
```

«Сокращённая версия» — только обязательные пункты дня: шейный протокол и основное движение (блоки `neck` и `main`). Лучше это, чем ноль: серия сохраняется. Флаг сокращённой версии живёт в состоянии тренировки, поэтому следующие подходы собираются из того же короткого списка.

## Недельный отчёт (воскресенье вечером)

```
   Неделя 32 · 6 из 7 тренировок · 84 минуты

   Шея: среднее 0.8 (было 1.4) ↓
   Прогресс: отжимания с колен → с пола,
             тяга 5 кг ×12 → ×15
   Тренировок по теме: 3

   Следующая неделя — разгрузочная: меньше подходов, уровни не меняются.
```

## Тон

Короткие фразы, без бодрого фитнес-мотивационного шума и без обращений «чемпион». Пропущенный день — констатация факта, не упрёк. Эмодзи — как маркеры структуры, не как эмоции.

## Ошибки

Любое исключение → пользователю понятная строка `Что-то сломалось на шаге «тяга». Тренировка сохранена, попробуй /go.` и одновременно техническое сообщение с трейсом мне же. Тренировка никогда не теряется: каждый подход пишется в базу сразу, а не в конце.
