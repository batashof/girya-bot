# 04. UX бота: команды и сценарии

Принцип: **минимум набора текста**. Всё, что можно, — инлайн-кнопки. Утренний сценарий должен проходиться одной рукой, не глядя.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Онбординг (только при первом запуске), дальше — краткая справка |
| `/today` | Тренировка на сегодня + кнопка «Начать» |
| `/go` | Сразу войти в пошаговый режим |
| `/pain` | Отметить боль в шее/спине сейчас → бот перестраивает день |
| `/skip` | Пропустить сегодня (спросит причину: устал / нет времени / болит / болею) |
| `/stats` | Объём, частота, тренд по шее, прогресс в базовых движениях |
| `/streak` | Текущая и рекордная серия |
| `/swap` | Заменить упражнение в текущей тренировке |
| `/howto <код>` | Техника упражнения и типичные ошибки |
| `/settings` | Время напоминания, часовой пояс, веса гирь, инвентарь |
| `/pause 3` | Пауза на N дней (болезнь, поездка) — без потери серии |
| `/export` | CSV со всеми сессиями |
| `/help` | Список команд |

## Онбординг (`/start`, один раз)

Пять вопросов, все кнопками, кроме весов:

1. **Часовой пояс** — кнопки с 3–4 частыми вариантами + «другой» (текстом).
2. **Во сколько напоминать?** — кнопки: 06:30 / 07:00 / 07:30 / 08:00 / другое.
3. **Какие гири есть?** — текстом через запятую: `16, 24`. Бот подтверждает разбор.
4. **Инвентарь** — турник? резина? (да/нет).
5. **Уровень** — «начинаю/возвращаюсь» или «тренируюсь регулярно». Влияет на стартовые повторы и веса.

Финал: показывает завтрашний день и предупреждение из [10-safety.md](10-safety.md).

## Утренний сценарий

```
07:30  🏋️ Понедельник — Тяга и задняя цепь
       ~28 мин · тяжёлый день

       Шея сегодня?
       [ 0 ок ] [ 1 тянет ] [ 2 болит ] [ 3 сильно ]
```

Ответ 0–1 — день идёт как есть. Ответ 2 — из дня убираются упражнения с `neck_safe = 0`, объём режется на 30%. Ответ 3 — день целиком заменяется на восстановительный протокол (W-D) и бот напоминает про красные флаги.

```
       План:
       1. Шейный протокол — 3 мин
       2. Становая с гирей — 5×5 × 24 кг
       3. Тяга одной рукой — 4×10 × 24 кг
       4. Свинги — 5×15 × 24 кг
       5. Prone Y / T / W — 3×10
       6. Чемоданная переноска — 4×30 шагов × 24 кг

       [ ▶️ Начать ]  [ 🕐 Через час ]  [ 🔁 Заменить упражнение ]  [ ⏭ Пропустить ]
```

## Пошаговый режим

Одно сообщение, которое редактируется на месте (`editMessageText`) — чат не засоряется.

```
   2/6 · Становая с гирей          подход 2 из 5
   ────────────────────────────────
   24 кг × 5 повторов
   Спина прямая, таз назад, гиря идёт вдоль голеней.

   [ ✅ Готово ]  [ 😮‍💨 Тяжело ]  [ 😴 Легко ]
   [ 🤕 Больно ]  [ ⏭ Пропустить упражнение ]
```

- **Готово** — записывает подход как выполненный по цели, показывает следующий.
- **Тяжело / Легко** — то же самое плюс пометка `feedback`, которая влияет на прогрессию.
- **Больно** — упражнение снимается с сегодня, спрашивает где болит, отмечает в логе и предлагает замену.
- Ввод фактического числа повторов — только если оно отличается от цели: кнопка `✏️ другое` → цифровая клавиатура.

Между подходами — строка «Отдых 60 сек» без блокировки: жать «Готово» можно когда угодно (серверных таймеров в MVP нет, см. [01-plan.md](01-plan.md) M6).

Финал:

```
   ✅ Готово за 26 мин. Объём: 3 240 кг.
   Серия: 12 дней 🔥
   Завтра: Шея и лопатки, ~15 мин.
```

## Вечерний пинг

Если к `evening_ping_at` сессия не в статусе `done`:

```
   Ещё не тренировался. Есть 12 минут?
   [ ▶️ Сокращённая версия ]  [ ⏭ Пропустить сегодня ]
```

«Сокращённая версия» — только обязательные пункты дня (шейный протокол + одно базовое движение). Лучше 12 минут, чем ноль: серия сохраняется.

## Недельный отчёт (воскресенье вечером)

```
   Неделя 32 · 5 из 7 тренировок

   Объём: 18 200 кг (+8% к прошлой)
   Шея: среднее 0.8 (было 1.4) ↓
   Прогресс: тяга 24×10 → 24×12, свинг 24 → 28

   Следующая неделя — разгрузочная: объём -40%.
```

## Тон

Короткие фразы, без бодрого фитнес-мотивационного шума и без обращений «чемпион». Пропущенный день — констатация факта, не упрёк. Эмодзи — как маркеры структуры, не как эмоции.

## Ошибки

Любое исключение → пользователю понятная строка `Что-то сломалось на шаге «тяга». Тренировка сохранена, попробуй /go.` и одновременно техническое сообщение с трейсом мне же. Тренировка никогда не теряется: каждый подход пишется в базу сразу, а не в конце.
