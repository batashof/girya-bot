# 06. Библиотека упражнений

Источник для `data/exercises.seed.json` (M2). Колонки соответствуют таблице `exercises` из [03-data-model.md](03-data-model.md).

Инвентарь: **пара гирь по 5 кг**, коврик, стена, стул/стол. Опционально: турник, резина, рюкзак с книгами (регулируемый вес).

Обозначения:
**Инв.** — `—` вес тела, `Г` гиря 5 кг, `2Г` две гири, `Р` резина, `Т` турник, `С` стена/пол/стул, `Рюк` рюкзак.
**Ур.** — уровень в лестнице прогрессии (см. раздел «Лестницы» в конце).
**Шея** — можно ли делать в день с болью в шее (`neck_safe`).

> Про вес: 5 кг — это мало для ног и спины, но ровно то, что нужно для шеи, лопаток и ротаторов плеча. Там, где пятёрка бессмысленна, в таблице стоит вес тела или рюкзак, и это осознанный выбор, а не компромисс — см. [05-training-program.md](05-training-program.md).

## Лестницы прогрессии

Хранятся в таблице `chain_steps` (сид — `data/chains.seed.json`), текущая ступень пользователя — в `progression.chain_level`. Шаг вверх — только по правилу из [05-training-program.md](05-training-program.md): верхняя граница повторов, фидбэк не «тяжело», две тренировки подряд.

Ступень — это не всегда другое упражнение: в тяге уровни 1 и 2 отличаются только темпом, а 4–6 — положением ног в одном и том же `RW7`. Поэтому у каждой ступени свой код упражнения плюс уточнение варианта.

**Отжимания (`push`)** — всё `PR3`, меняется опора и рычаг
1. От стены → 2. От стола/подоконника → 3. С колен → 4. С пола → 5. С пола с паузой 2 с внизу → 6. Узкие / ноги на стуле → 7. С отрывом рук / «лучник»

**Тяга (`row`)**
1. `RW1` тяга гири одной рукой 5 кг × 12–15 → 2. `RW1` с темпом 3-1-3 → 3. `RW8` тяга рюкзака (вес книгами) → 4. `RW7` тяга под столом, ноги согнуты → 5. `RW7` ноги прямые → 6. `RW7` ноги на возвышении → 7. `RW6` подтягивания (если есть турник)

**Присед (`squat`)**
1. `LG5` присед с весом тела → 2. `LG5` гоблет-присед 5 кг → 3. `LG5` с паузой 3 с внизу → 4. `LG2` выпад назад → 5. `LG4` болгарский присед → 6. `LG4` болгарский с гирями → 7. `LG6` присед на одной ноге к стулу

**Тазовый шарнир (`hinge`)**
1. `PC5` good morning с гирей → 2. `PC1` румынская тяга двумя ногами 2×5 кг → 3. `PC2` румынская на одной ноге без веса → 4. `PC2` с гирей → 5. `PC9` становая с рюкзаком → 6. `PC4` свинг одной рукой

**Кор (`core`)**
1. `CR6` dead bug → 2. `PC7` bird dog с паузой → 3. `CR1` планка 60 с → 4. `CR1` с отрывом руки → 5. `CR2` боковая планка с подъёмом ноги

**Шея (`neck`)** — уровня нет. Растёт только время удержания и количество подходов, вес не добавляется никогда.

Ступени, требующие инвентаря (`RW8`, `PC9` — рюкзак; `RW6` — турник), помечены в сиде полем `requires`. Если инвентаря нет, бот берёт ближайшую доступную ступень ниже, а не встаёт.

> Лестница `core` пока ни в одном дне недели не используется: планок и dead bug нет ни в одном из семи шаблонов (`CR1`, `CR2`, `CR6` встречаются только как ступени). Либо кор должен появиться в составе дня, либо лестница лишняя — решается при пересмотре программы.

## Правила замен

- Замена берётся из той же `swap_group` и должна быть доступна по инвентарю.
- Нет турника → `vertical_pull` заменяется на `horizontal_row`.
- Нет резины → `SC5` face pull заменяется на `SC10` обратную «муху» с гирями.
- Нет рюкзака → остаётся вариант с весом тела следующего уровня.
- Ручная замена запоминается на 7 дней; «навсегда» — через `/settings`.

## Что осознанно исключено

| Упражнение | Почему |
| --- | --- |
| Становая и присед с гирей как силовые | 5 кг при массе тела 73 кг не создают стимула. Их роль отдана вариантам с весом тела и рюкзаку |
| Тяга к подбородку узким хватом | Риск импинджмента плеча, а цель закрывается face pull'ом |
| Шраги | Верхняя трапеция и так перегружена рюкзаком — её надо разгружать и растягивать, а не качать |
| Борцовский мост, мост на голове | Осевая нагрузка на шею при имеющейся симптоматике — неоправданный риск |
| Жим из-за головы | Крайняя позиция плеча, часто добирается за счёт шеи |
| Резкие круговые вращения головой | Лишняя нагрузка на суставы шеи, заменены изометрией |
| Работа до отказа, «до жжения» | Противоречит ежедневному режиму: завтра нужно суметь повторить |
