# Girya Bot 🏋️

Личный Telegram-бот для ежедневных домашних тренировок: **15 минут утром, каждый день, без фанатизма**.
Цель — здоровье и крепкое тело, а не масса. Упор — **спина, лопатки и шея** (профилактика боли от рюкзака и тяжёлой верхней одежды).

Инвентарь: пара гирь по 5 кг + вес тела. Стоимость эксплуатации: **$0/мес** (Cloudflare Workers + D1 в бесплатных лимитах).

---

## Что делает

- Каждое утро присылает тренировку дня: 3 упражнения, подходы, повторы. Ровно на 15 минут.
- Ведёт по тренировке пошагово: упражнение → выполнил → следующее. Логирует всё в базу.
- Каждый день начинается с 3-минутного **шейного протокола** — это ядро программы, а не разминка.
- Растит нагрузку по лестнице рычага (вес зафиксирован на 5 кг): повторы → темп → сложность варианта.
- Реагирует на обратную связь: «тяжело» / «легко» / «болит шея» меняют завтрашний день.
- `/mini` — трёхминутные микро-блоки для шеи и осанки в течение дня.
- Считает серию (streak), показывает статистику и недельный отчёт.
- Всё настраивается: время, рост/вес/возраст, бюджет минут, инвентарь.
- К каждому упражнению — техника по шагам и рисованная схема движения: куда идёт таз, что остаётся прямым.

## Стек

- **TypeScript** + [grammY](https://grammy.dev) — фреймворк для Telegram-ботов
- **Cloudflare Workers** — рантайм (webhook + cron triggers)
- **Cloudflare D1** — SQLite-база
- **Wrangler** — локальная разработка и деплой
- **GitHub Actions** — деплой на push в `main`
- **Vitest** — тесты движка программы

## Статус

M0–M5 готовы: бот сам будит утром с учётом часового пояса, спрашивает про шею и
перестраивает день под боль, ведёт тренировку пошагово, считает прогрессию и серию,
шлёт недельный отчёт и умеет `/stats`, `/streak`, `/export`, `/mini`, `/pain`,
`/skip`, `/pause`, `/settings`. Осталось M6 — приятное сверху.
См. [план](docs/01-plan.md).

## Быстрый старт

```bash
pnpm install
cp .dev.vars.example .dev.vars   # токен dev-бота от @BotFather
pnpm db:local                    # схема + контент справочников в локальную D1
pnpm dev                         # локальный воркер + dev-бот в polling
```

Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test`.
Прод разворачивается по [08-deployment.md](docs/08-deployment.md); дальше деплоит CI на push в `main`.
